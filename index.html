FAQ

answers

Why does my antivirus flag the launcher?
Game-modification tools work through process injection — the same technique some malware uses — so heuristic engines often flag them as a false positive. The launcher contains no malicious code: it writes its payload to the game process and nothing else. If your AV blocks it, add an exclusion for the folder and re-download. This is expected behavior for any tool in this category.
What are the requirements?
Windows 10 or 11 (64-bit) and the current Steam version of Lockdown Protocol. No extra runtimes or frameworks — the launcher is fully self-contained.
How do updates work?
The launcher checks for a new version on every start and updates itself automatically. When the game patches, updated builds go out through the same channel — just relaunch.
Is this safe to use? Will I get banned?
PROJECT SAFT is private community software with a small user base. That said, no game modification is ever zero-risk: use it in private lobbies, don't stream it openly, and accept that you use it at your own risk.
How do I open the menu in-game?
Press INSERT to toggle the menu and M for the big map. Nearly every action can be rebound to your own keys in the Hotkeys tab.
